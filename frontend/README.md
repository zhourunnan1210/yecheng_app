# yecheng_app_h5 前端项目

## 项目简介

yecheng_app_h5是一个基于 uni-app 框架开发的跨平台 H5 应用，主要服务于人才服务、政策分析、金融服务等业务场景。项目采用 Vue.js + uView UI 技术栈，支持多端部署。

## 技术架构

### 前端技术栈
- **框架**: Vue.js 2.x + uni-app
- **UI组件库**: uView UI
- **状态管理**: Vuex
- **图表库**: ECharts / uCharts
- **构建工具**: uni-app CLI
- **样式**: SCSS/CSS

### 项目结构
```
yecheng_app_h5/
├── components/          # 公共组件库
├── pages/              # 页面文件
├── static/             # 静态资源
├── store/              # 状态管理
├── utils/              # 工具函数
├── App.vue             # 应用入口
├── main.js             # 主入口文件
├── manifest.json       # 应用配置
└── package.json        # 依赖配置
```

## 核心功能模块

### 1. 人才服务模块 (`/pages/talent/`)
- **人才中心**: 人才信息展示、简历管理

- **可视化**: 人才数据统计图表展示

### 2. 政策服务模块 (`/pages/policy/`)
- **政策发布**: 最新政策信息展示
- **政策分析**: 政策解读、影响分析
- **政策详情**: 政策全文、申请条件

### 3. 金融服务模块 (`/pages/finance/`)
- **融资服务**: 融资需求发布、产品展示
- **信用查询**: 企业信用信息查询
- **融资机构**: 金融机构信息展示

### 4. 数据统计模块 (`/pages/dataStatistics/`)
- **数据可视化**: 各类业务数据图表展示
- **统计分析**: 数据趋势分析、报表生成

### 5. 用户认证模块 (`/pages/auth/`)
- **用户注册**: 多角色注册（企业、高校、服务机构等）
- **用户登录**: 统一登录认证
- **权限管理**: 基于角色的权限控制

### 6. 内容管理模块
- **新闻资讯**: 行业新闻、动态资讯
- **园区信息**: 科技园区介绍、政策支持
- **问答社区**: 用户提问、专家解答

### 部署配置

#### 1. 后端接口地址（打包前必改）

打开 `utils/api.js`，把 `BASE_URL` 改成后端地址：

```javascript
// 本地开发
const BASE_URL = "http://localhost:10086"
// 部署后（改成你的域名或服务器 IP）
const BASE_URL = "http://your-domain.com:10086"
```

所有请求都会拼在这个地址后面。**改完再打包**，否则打出来的页面会去请求 `localhost`。

#### 2. 应用标识与域名

`manifest.json` 里有三个占位符需要替换成你自己的：

| 位置 | 当前值 | 说明 |
|------|--------|------|
| 顶层 `appid` | `__UNI__PLACEHOLDER` | 在 HBuilderX 里点「重新获取」生成你自己的 uni-app 标识 |
| `mp-weixin.appid` | `wx0000000000000000` | 只在要发微信小程序时才需要填 |
| `h5.domain` | `your-domain.com` | 部署域名，影响部分静态资源引用 |

#### 3. 隐私协议链接

`androidPrivacy.json` 里的服务协议与隐私政策链接目前指向 `https://your-domain.com`，
打包 App 前换成你实际部署的页面地址。

#### 4. 打包 H5

HBuilderX 菜单栏 **发行 → 网站-H5 手机版**，产物在 `unpackage/dist/build/h5/`，
把这些文件复制到 `../deploy/nginx/html/` 即可由 Nginx 提供访问。

#### 5. 跨平台构建 / 静态资源部署

暂无方案，当前只验证了 H5 单端。

## 开发指南

### 代码规范
- 使用 Vue.js 官方风格指南
- 组件命名采用 PascalCase
- 文件命名采用 kebab-case
- 遵循 uni-app 开发规范

### 组件开发
- 组件放置在 `components/` 目录
- 每个组件包含 `.vue` 文件和必要的样式文件
