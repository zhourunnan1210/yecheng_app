# 椰城项目部署指南（傻瓜式教学）

> 适用环境：阿里云 ECS + Windows 本地开发。跟着一步步做就能部署成功。
>
> 本文是一份**速查版**流程；更完整的说明（含云服务器选购、HTTPS、OSS 配置、排错）
> 见 [`deploy/README.md`](../deploy/README.md)。

> ⚠️ **先看这条**：本文按**混合水印方案**（LSB + SteganoGAN）描述，但仓库里
> `watermark-service/Dockerfile` 实际构建的是 **LSB-only 版本**——不带 SteganoGAN，
> 也不需要 Redis 任务队列。所以文中"两条 python 进程""内存改 6G"等步骤，
> 只有在你自行构建了 SteganoGAN 完整版镜像后才适用。

---

## 一、你需要准备什么

| 项目 | 要求 |
|------|------|
| 阿里云 ECS | **2核16G**（必须，Python 水印需要大内存） |
| 操作系统 | Ubuntu 22.04 |
| 本地 Windows | 安装 Docker Desktop + HBuilderX + FileZilla |
| WSL | Ubuntu，安装 Docker |

---

## 二、阿里云安全组配置

阿里云 ECS 控制台 → 安全组 → 入方向 → 添加以下规则：

| 端口 | 用途 | 授权对象 |
|------|------|----------|
| 22 | SSH | 0.0.0.0/0 |
| 80 | 前端页面 | 0.0.0.0/0 |
| 443 | HTTPS | 0.0.0.0/0 |
| 10086 | 后端 API | 0.0.0.0/0 |
| 3306 | MySQL（Navicat 连接） | 你的本机 IP |
| 6379 | Redis | 你的本机 IP |
| 5001 | 水印服务（调试） | 你的本机 IP |

## 三、WSL 中构建 Python 镜像并推送到阿里云

### 3.1 确认文件齐全

打开 WSL 终端，进入 ImgStegano 目录：

```bash
cd /home/master/ImgStegano
ls -la
```

确保有以下文件：
- `Dockerfile`
- `ImgStegano_cloud.py`
- `worker_encode_cloud.py`
- `docker-entrypoint.sh`

缺文件的话从 Windows 目录拷贝：
```bash
cp /mnt/d/Code/watermark-service/ImgStegano_cloud.py .
cp /mnt/d/Code/watermark-service/worker_encode_cloud.py .
cp /mnt/d/Code/watermark-service/docker-entrypoint.sh .
```

### 3.2 Docker Desktop 配置镜像加速

Windows 右下角小鲸鱼图标 → 右键 → Settings → Docker Engine，粘贴：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io"
  ]
}
```

点 Apply & restart，等鲸鱼不转圈。

### 3.3 构建镜像

```bash
docker build -t imgstegano:latest .
```

耗时 10-20 分钟，不要中途取消。

### 3.4 推送到阿里云容器镜像服务（ACR）

**浏览器操作（一次性）：**

1. 打开 [阿里云容器镜像服务](https://cr.console.aliyun.com)
2. 左侧点"实例列表"，区域选和你 ECS 一样的
3. 左侧"命名空间" → 创建命名空间，填 `your-namespace`
4. 左侧"镜像仓库" → 创建镜像仓库：
   - 命名空间选 `your-namespace`
   - 仓库名填 `imgstegano`
   - 仓库类型选**公开**
5. 左侧"访问凭证" → 设置固定密码（记住密码！）

**WSL 终端执行：**

```bash
# 登录（用户名是你的阿里云账号，去 ACR 页面复制完整命令）
docker login --username=你的阿里云账号 crpi-xxxxxx.cn-shenzhen.personal.cr.aliyuncs.com

# 打标签（仓库地址去 ACR 页面复制"公网地址"）
docker tag imgstegano:latest crpi-xxxxxx.cn-shenzhen.personal.cr.aliyuncs.com/your-namespace/imgstegano:latest

# 推送
docker push crpi-xxxxxx.cn-shenzhen.personal.cr.aliyuncs.com/your-namespace/imgstegano:latest
```

## 四、服务器安装 Docker

SSH 连接 ECS（FinalShell 或 XShell），逐行复制执行：

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
systemctl start docker && systemctl enable docker

# 安装 Docker Compose
curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 配置镜像加速
cat > /etc/docker/daemon.json << 'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io"
  ]
}
EOF
systemctl restart docker
```

## 五、用 FileZilla 上传项目

打开 FileZilla，顶部填写：

| 字段 | 值 |
|------|-----|
| 主机 | `sftp://你的ECS公网IP` |
| 用户名 | `root` |
| 密码 | ECS root 密码 |
| 端口 | 22 |

点快速连接，然后上传以下内容：

| 本地路径 | 服务器目标路径 |
|----------|----------------|
| `backend/target/highly-new-app-0.0.1-SNAPSHOT.jar` | `/opt/yecheng/backend/target/` |
| `backend/Dockerfile` | `/opt/yecheng/backend/Dockerfile` |
| `D:\Code\yecheng_app\deploy\` 整个目录 | `/opt/deploy/` |
| 前端 H5 打包产物（`unpackage/dist/build/web/` 下所有文件） | `/opt/deploy/nginx/html/` |

上传前端后，在服务器确认：

```bash
ls /opt/deploy/nginx/html/index.html
```

如果找不到说明传错目录了，检查一下。

## 六、配置环境变量并启动

### 6.1 创建 .env 文件

```bash
cd /opt/deploy
cp .env.example .env
```

### 6.2 确保数据库 SQL 就位

```bash
ls /opt/deploy/../database/yecheng_app_2604.sql
```

没有的话说明 database/ 目录没上传完整，用 FileZilla 补传 `database/yecheng_app_2604.sql`。

### 6.3 修改 docker-compose.yml 中 Python 镜像地址

```bash
cd /opt/deploy
nano docker-compose.yml
```

找到 imgstegano 部分，把 `build:` 注释掉，换成 `image:`：

```yaml
  imgstegano:
    image: crpi-xxxxxx.cn-shenzhen.personal.cr.aliyuncs.com/your-namespace/imgstegano:latest
    # build:
    #   context: ../python/ImgStegano
    #   dockerfile: Dockerfile
```

> 注意：如果你的 ACR 仓库地址和上面不一样，以 ACR 页面显示的公网地址为准。

同时确认内存限制已经改为 6G：

```yaml
    deploy:
      resources:
        limits:
          memory: 6G
```

按 `Ctrl+O` → 回车保存 → `Ctrl+X` 退出。

### 6.4 在服务器登录 ACR 并拉取镜像

```bash
docker login --username=你的阿里云账号 crpi-xxxxxx.cn-shenzhen.personal.cr.aliyuncs.com
# 输入固定密码

docker pull crpi-xxxxxx.cn-shenzhen.personal.cr.aliyuncs.com/your-namespace/imgstegano:latest
```

### 6.5 启动所有服务

```bash
cd /opt/deploy && docker-compose up -d
```

首次启动会拉取 MySQL、Redis、Nginx 镜像并构建 Java 后端，约 5-10 分钟。

## 七、验证部署

### 7.1 确认容器都在运行

```bash
docker ps
```

应该看到 5 个容器全部 `Up`：
- yecheng-nginx
- yecheng-app
- yecheng-watermark
- yecheng-redis
- yecheng-mysql

### 7.2 确认 Python 水印服务正常

等 60 秒让模型加载完：

```bash
sleep 60
curl http://localhost:5001/health
```

返回 `{"redis":"ok","service":"imgstegano","status":"healthy"}` 即正常。

### 7.3 确认 Flask 和 Worker 都在

```bash
docker exec yecheng-watermark ps aux | grep python
```

应该看到**两条** python 进程（一个 Flask，一个 Worker）。

### 7.4 导入数据库

```bash
docker exec -it yecheng-mysql bash
```

进入容器后：

```bash
mysql -uroot -p'你的数据库密码' yecheng_app_2604
```

看到 `mysql>` 提示符后：

```sql
source /docker-entrypoint-initdb.d/yecheng_app_2604.sql;
```

等 30 秒导入完成，输入 `exit` 两次退出。

### 7.5 浏览器测试

| 测试项 | 地址 |
|--------|------|
| 前端首页 | `http://你的公网IP` |
| 后端 API | `http://你的公网IP:10086` |
| 水印健康检查 | `http://你的公网IP:5001/health` |

- 前端应显示首页
- 后端显示 Whitelabel Error Page 是**正常的**（没有根路径接口）
- 水印返回 healthy JSON

## 八、故障排查速查表

每次失败后在服务器执行这 5 条命令：

```bash
docker ps
docker exec yecheng-watermark ps aux | grep python
docker logs yecheng-watermark --tail 10
docker logs yecheng-app 2>&1 | grep -v "mybatis\|sql\|ibatis\|druid\|CGLIB\|p6spy" | tail -10
free -m | grep Mem
```

### 常见问题对照

| 现象 | 原因 | 解决 |
|------|------|------|
| Flask 不在 ps 里 | 容器内存限制不足 | docker-compose.yml 中 memory 改 6G |
| 日志有 `Killed` | 同上 | 同上 |
| 日志有 `Connection refused` | Flask 挂了 | 检查上方原因 |
| `docker pull` 超时 | 镜像源被墙 | 换 `docker.m.daocloud.io` |
| 登录 500 | 数据库没导入 | 执行七.4 导入 SQL |
| 前端白屏/403 | 前端文件没放对 | FileZilla 确认 `/opt/deploy/nginx/html/index.html` 存在 |
| `Table doesn't exist` | 数据库没导入 | 执行七.4 |
| 前端 API 请求 500 | 后端代码 bug | 查看 Java 日志 |

## 九、更新代码后如何重新部署

| 改了什么 | 操作 |
|----------|------|
| 前端 (.vue/.js) | HBuilderX 重新打包 → FileZilla 覆盖 `/opt/deploy/nginx/html/` → 浏览器 Ctrl+F5 |
| Java 后端 | `mvn clean package -DskipTests` → FileZilla 覆盖 jar → `cd /opt/deploy && docker-compose up -d --build yecheng-app` |
| Python 服务 | WSL 中 `docker build` + `docker push` → 服务器 `docker pull` + `docker-compose up -d imgstegano` |
| 数据库 | Navicat 连接直接改，或 `docker exec -it yecheng-mysql mysql -uroot -p` |

## 十、运维常用命令

```bash
# 查看日志
docker logs -f yecheng-app        # Java 后端实时日志
docker logs -f yecheng-watermark  # Python 水印实时日志
docker logs --tail 100 yecheng-app

# 重启服务
docker-compose restart              # 全部重启
docker-compose restart yecheng-app  # 只重启后端
docker-compose restart imgstegano   # 只重启水印

# 停止/启动
docker-compose down                 # 停止并删除容器（数据不丢）
docker-compose up -d                # 启动
docker-compose down -v              # 停止并删除数据卷（数据清空！慎用）

# 备份数据库
docker exec yecheng-mysql mysqldump -uroot -p'你的数据库密码' yecheng_app_2604 > backup.sql
```
