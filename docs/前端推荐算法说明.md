# 增强版推荐系统使用说明

## 🚀 概述

增强版推荐系统已经成功应用到前端项目中，提供了更智能、更精准的推荐功能。

## 📋 主要特性

### 1. 多维度标签提取
- **职位标签**: 职位名称匹配
- **地点标签**: 工作地点匹配  
- **学历标签**: 学历要求匹配
- **薪资标签**: 薪资范围匹配
- **特色标签**: 岗位特色/个人品质匹配

### 2. 语义相似性计算
- **职位相似性**: "Java开发" ↔ "Java后端开发", "Java工程师"
- **技能相似性**: "Java" ↔ "Spring", "SpringBoot", "MyBatis"
- **地点相似性**: "北京" ↔ "北京市", "海淀区", "朝阳区"
- **薪资相似性**: 基于重叠度计算相似分数

### 3. 智能推荐算法
- **多维度权重计算**:
  - 职位匹配: 40%权重
  - 地点匹配: 20%权重
  - 学历匹配: 10%权重
  - 薪资匹配: 20%权重
  - 特色匹配: 10%权重

- **混合推荐策略**:
  - 70%个性化推荐
  - 30%最新内容
  - 智能兜底机制
